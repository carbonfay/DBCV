# Мок-тесты для интеграций

Этот каталог содержит мок-тесты для интеграций платформы DBCV.

## Moodle Get Courses

Файл `test_moodle_get_courses.py` содержит комплексные мок-тесты для интеграции `moodle_get_courses`.

### Запуск тестов

#### Вариант 1: Использование pytest (рекомендуется)

В окружении с установленными зависимостями:

```bash
cd backend
pytest app/tests/integrations/mocks/test_moodle_get_courses.py -v
```

#### Вариант 2: Простой скрипт (для быстрой проверки)

Для быстрой проверки без полного окружения:

```bash
cd backend
python app/tests/integrations/mocks/run_tests_simple.py
```

### Покрытие тестами

Тесты покрывают следующие сценарии:

1. **Метаданные интеграции** - проверка правильности метаданных
2. **Успешное выполнение** - получение списка курсов
3. **Успешное выполнение с trailing slash** - обработка URL со слэшем в конце
4. **Альтернативные ключи credentials** - поддержка `moodle_url` и `wstoken`
5. **Отсутствуют credentials** - обработка ошибки отсутствия credentials
6. **Отсутствует URL** - обработка ошибки отсутствия URL в credentials
7. **Отсутствует API key** - обработка ошибки отсутствия токена
8. **Ошибка Moodle API** - обработка ошибок, возвращаемых Moodle API
9. **HTTP ошибка** - обработка HTTP статус ошибок
10. **Ошибка соединения** - обработка ошибок сетевого соединения
11. **Неожиданная ошибка** - обработка общих исключений
12. **Credentials в корне** - поддержка credentials без `payload`
13. **Курсы в формате словаря** - обработка разных форматов ответа

### Структура тестов

Все тесты используют `unittest.mock` для мокирования:
- `httpx.AsyncClient` - для мокирования HTTP запросов к Moodle API
- `CredentialsResolver` - для мокирования получения credentials
- `BotLogger` - для мокирования логирования
