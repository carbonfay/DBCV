## 📖 Описание

DBCV — это мощный инструмент для разработки бизнес-решений, не требующий глубоких знаний в программировании. Вы сможете создавать и развертывать сложные мультиагентные системы в считанные минуты, используя визуальный интерфейс и возможности Python.

Платформа позволяет строить сложные бизнес-процессы через визуальный конструктор, где каждый блок может выполнять определенную функцию: обработку данных, взаимодействие с внешними API, выполнение Python-кода или условные переходы.

### 🎯 Основные преимущества

- 🚀 **Мультиагентные системы без DevOps** — создавайте сложные системы из взаимодействующих агентов без необходимости настройки инфраструктуры
- ⏱️ **Микросервисы за 30 минут** — быстрое прототипирование и развертывание бизнес-логики
- 🎨 **Визуальный конструктор сценариев** — интуитивно понятный интерфейс для построения сложных процессов
- 🛡️ **Устойчивость к энтропии** — надежная архитектура, способная обрабатывать высокие нагрузки

## ✨ Ключевые особенности

### 💻 Онлайн-разработка
Работайте прямо в браузере со встроенной средой разработки. Не требуется установка дополнительного ПО для создания и редактирования сценариев.

### 🐍 Python-интеграция
Используйте Python для обработки данных и выполнения сложных вычислений. Каждый блок может содержать Python-код для реализации бизнес-логики.

### 🗄️ Встроенные базы данных
Храните данные прямо в платформе, используя четыре основных типа таблиц и их комбинации:
- **Bot Variables** — переменные уровня бота
- **User Variables** — переменные уровня пользователя
- **Session Variables** — переменные уровня сессии
- **Channel Variables** — переменные уровня канала

### 🔗 API и вебхуки
Подключайтесь к внешним сервисам и принимайте вебхуки для интеграции с вашими системами. Каждый агент может иметь собственный внешний API.

### 🌐 Внешние API для каждого агента
Каждый сервис-агент имеет внешний API и может отправлять внешние запросы, что позволяет строить сложные цепочки, сети, кольца и петли взаимодействия между сервисами.

### 🖱️ Создание блоков в один клик
Легко добавляйте блоки в сценарии, связывайте их и получайте визуальные индикаторы состояния выполнения.

### ⚙️ Гибкая настройка
Настраивайте условия перехода между блоками, редактируйте код и используйте внешние API-запросы для реализации сложной логики.

### 🎛️ Контролируемая сложность
Управляйте сложностью сценариев, связывая блоки и используя абстракции для организации кода.

### 🤝 Коллаборация
Работайте в команде над созданием сложных систем, используя возможности совместной разработки.

### 💰 Экономия
Сократите время разработки и затраты на создание бизнес-приложений благодаря визуальному подходу.

### 🧩 Комбинирование сервисов
Объединяйте различные сервисы и интеграции для создания комплексных решений.

### 🧱 Активные блоки
Каждый блок может выполнять активные действия: отправку сообщений, выполнение запросов, обработку данных.

### ⏰ Таймеры и счетчики
Используйте встроенные механизмы для отложенных задач и периодических операций.

### 📲 Виджеты
Создавайте интерактивные элементы интерфейса для взаимодействия с пользователями.

## 🏗️ Архитектура и концепции

Платформа построена на основе следующих концепций, позволяющих организовать сложные системы из множества взаимодействующих компонентов:

### 🔷 Агент (Атом)
Базовый функциональный элемент, который может выполнять роль, похожую на метод в традиционной архитектуре MVC. Агенты формируются из блоков (шагов) и могут подключаться друг к другу для выполнения сложных задач.

**Характеристики:**
- Состоит из одного или нескольких шагов
- Имеет собственный API для внешнего взаимодействия
- Может хранить переменные на уровне бота
- Выполняет определенную бизнес-функцию

### 🔶 Молекула
Группа взаимодействующих между собой агентов, объединенных для выполнения более сложной задачи. Молекулы позволяют организовать логически связанные агенты в единую систему.

**Характеристики:**
- Объединяет несколько агентов
- Обеспечивает взаимодействие между агентами
- Реализует сложный бизнес-процесс

### 🔸 Материал
Абстрактный уровень управления молекулами, позволяющий организовать их в сложные комбинации. Материалы используются для построения крупных системных решений.

**Характеристики:**
- Управляет группой молекул
- Обеспечивает координацию между различными процессами
- Позволяет создавать многоуровневые системы

### 🔹 Организм
Сложная экосистема из агентов, молекул и материалов, редко взаимодействующая с другими организмами. Организмы представляют собой полностью автономные системы.

**Характеристики:**
- Максимальный уровень абстракции
- Автономная система с минимальными внешними зависимостями
- Реализует комплексные бизнес-решения

> **Примечание:** Границы между молекулами, материалами и организмами условны и предназначены для организации сложных систем из множества сервисов. Выбор уровня абстракции зависит от конкретной задачи.

## 💻 Установка

Для установки и настройки платформы локально см. подробную [инструкцию по установке](INSTALLATION.md).

### Краткая инструкция

#### Требования

- **Python**: 3.12 или выше
- **PostgreSQL**: 14 или выше
- **Redis**: 7 или выше
- **Docker и Docker Compose** (рекомендуется)

#### Быстрая установка через Docker

```bash
# Клонировать репозиторий
git clone https://github.com/carbonfay/DBCV.git
cd DBCV

# Настроить переменные окружения
cp env.example env.dev
# Отредактировать env.dev с необходимыми настройками

# Запустить все сервисы
docker-compose -f docker-compose.dev.yml up -d

# Проверить статус
docker-compose -f docker-compose.dev.yml ps
```

Подробнее см. [INSTALLATION.md](INSTALLATION.md)

## 🔧 Разработка

### Структура проекта

```
DBCV/
├── backend/                 # Backend приложение
│   ├── app/                # Основное приложение
│   │   ├── api/            # API endpoints
│   │   ├── crud/           # CRUD операции
│   │   ├── models/         # Модели базы данных
│   │   ├── schemas/        # Pydantic схемы
│   │   ├── engine/         # Движок выполнения ботов
│   │   └── integrations/   # Интеграции с внешними сервисами
│   ├── mcp/                # MCP сервер для AI-ассистента
│   └── requirements.txt    # Зависимости Python
├── docker-compose.yml       # Docker Compose для продакшена
├── docker-compose.dev.yml   # Docker Compose для разработки
└── env.example             # Пример файла переменных окружения
```

### Технологический стек

- **Backend**: FastAPI, FastStream, SQLAlchemy (async)
- **База данных**: PostgreSQL
- **Кэш и очереди**: Redis, Redis Streams
- **Хранилище файлов**: MinIO/S3
- **MCP Server**: AI-ассистент для создания ботов через AI

### Запуск в режиме разработки

```bash
# Активировать виртуальное окружение
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate      # Windows

# Установить зависимости
pip install -r backend/requirements.txt
pip install -r backend/requirements-dev.txt

# Запустить миграции
cd backend/app
alembic upgrade head

# Загрузить начальные данные
python initial_data.py

# Запустить сервер разработки
python main.py
```
